`cclens advise` and `cclens review` take `--project` to look at one project folder only, using the same names and paths as `tokens --project`. Sessions, daily tokens, compactions, recurring jobs and skill uses all come from that project; unused skills are reported as unused in this project, with a per-project way to turn them off first.
