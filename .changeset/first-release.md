First release. `cclens init` records every skill use through Claude Code hooks (or install the cclens Claude Code plugin and run `cclens init --plugin`). `skills`, `usage` and `tokens` show your skill inventory, skill use and token spend; `review` gives optimization advice from your own numbers, with an optional `--ai` second opinion; `search` finds skills across GitHub, SkillsMP and skills.sh, ranked by stars; `doctor` checks the setup.
